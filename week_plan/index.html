Topics by week

  1. Day 1: Setup, basic structure and elements
  2. Day 2: Links, buttons, and basic styles (premade)
  3. Day 3: Introduction to CSS, divs, and sections
  4. Day 4: Articles, nav, IDs, fragment links, basic CSS, and classes
  5. Day 5: IDs and basic images (figcaption, img)
  6. Day 6: Lists (ul, li), styling lists, and iframes
  7. Day 7: Advanced images, CSS borders, advanced classes, and IDs
  8. Day 8: Media queries, advanced text (em, i), and advanced CSS (animations, transitions)
  9. Day 9: Audio, video, and JavaScript intro (alert, confirm, prompt)
  10. Day 10: JavaScript intro (variables, basic logic, functions, and console.log)
  11. Day 11: Intermediate JavaScript (cookies, return)
  12. Day 12: Intermediate JavaScript (edit HTML with innerHTML, document.write, and getElementById)
  13. Day 13: onload, advanced cookies (expiration dates, path, etc.), and onclick
  14. Day 14: Random numbers (Math.floor(Math.random() * [range])) and exceptions (try, catch)
